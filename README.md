# TURF MVP

MVP веб-приложения для расчёта TURF (Total Unduplicated Reach) по Excel-файлу.

## Что делает MVP

Приложение:
- принимает файл `.xlsx`
- читает первый лист
- ожидает структуру: строки - респонденты, столбцы - опции
- принимает только бинарные значения `0/1`
- для каждого `k` от 1 до `max k` находит комбинацию с максимальным уникальным охватом
- показывает таблицу результатов
- строит кривую накопленного охвата
- выводит короткую подсказку по интерпретации результатов

## Наша версия MVP

В MVP зашита **точная exhaustive-логика** для расчёта лучшей комбинации по каждому размеру набора.

Что это значит:
- мы перебираем все комбинации от `k = 1` до выбранного `max k`
- для каждой комбинации считаем уникальный охват как долю респондентов, у которых есть хотя бы один позитивный ответ в наборе
- выбираем комбинацию с максимальным reach

## Что входит в MVP

- Exact TURF по бинарным данным
- Лучший набор для каждого `k`
- Reach в количестве и в процентах
- Прирост к предыдущему шагу
- График накопленного охвата
- Простая интерпретация под графиком

## Что не входит в MVP

- Frequency
- Weights
- Сегменты
- Ограничения типа must-have / must-not-have
- Approximate heats / ускоренные приближённые решения
- Выгрузка результатов обратно в Excel

## Ограничения MVP

- только `.xlsx`
- только первый лист
- только значения `0` и `1`
- максимум 20 столбцов с опциями
- максимум `k = 5`
- расчёт останавливается, если число комбинаций для точного перебора становится слишком большим

## Формат входного файла

Пример:

| Idea_A | Idea_B | Idea_C |
|---|---:|---:|
| 1 | 0 | 1 |
| 0 | 1 | 0 |
| 1 | 1 | 0 |

Важно:
- первая строка - заголовки столбцов
- каждая следующая строка - один респондент
- пустых ячеек быть не должно

## Что зафиксировано методологически

В этой версии продукта:
- позитивный ответ определяется как `1`
- reach считается как уникальный охват без двойного счёта респондентов
- график показывает максимальный reach по каждому размеру набора
- прирост показывает, сколько дополнительного охвата даёт переход к следующему размеру набора
